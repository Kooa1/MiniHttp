MiniHttp Server

A lightweight C++17 HTTP server built from scratch

epoll + state-machine parser + Master-Slave Multi-Reactor with ThreadPool. Middleware pipeline, static file serving, and dynamic routing.

C++17 epoll Multi-Reactor ThreadPool

Architecture

⚡

Event-Driven

epoll-based IO multiplexing with non-blocking sockets for high concurrency.

⚙️

State Machine

HTTP request parsing via a deterministic finite-state machine — no regex, no bloat.

🔄

Multi-Reactor

Master accepts connections; slave reactors handle IO in separate threads.

🧵

ThreadPool

CPU-intensive work offloaded to a worker pool, IO threads stay responsive.

🔗

Middleware

Pluggable request pipeline — logging, auth, or custom logic before the handler.

📁

Static Files

sendfile-based zero-copy serving with MIME type detection and path traversal protection.
